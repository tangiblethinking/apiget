How to Get Your API Key

Follow these steps to create a Google AI Studio API key

Step 1

Open Google AI Studio

Click the Get my API key button below. A new tab will open with the Google AI Studio API keys page.

Step 2

Create API key and project

Click Create API key at the top right. A popup will appear asking for a name — call it anything you want or leave it as is — and Choose an imported project.

  • Select Create project to make a new one.
  • In Name your project, name it anything you want or leave it as is.
Step 3

Create the project

Click Create project. Let it load; it will return you to the previous prompt.

Step 4

Create the key

Click Create key. Let it load; you will now see your API key.

Step 5

Copy your API key

Click the copy icon on the right of the API key text to copy it to your clipboard.

Step 6

Return here

Return to this tab and press Enter my key.

Step 7

Paste your key

Paste your key into the text field labeled Your API Key.

Step 8

Save your key

Click Save to store your API key.
